# Secure GenAI Landing Page

This is a responsive landing page for the Secure GenAI newsletter, built with React, Vite, and Tailwind CSS.

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

This will start the development server, and you can view the site at `http://localhost:5173`.
